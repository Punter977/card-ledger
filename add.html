GitHub connection settings

This page writes directly to your GitHub repo using a personal access token — no server involved, it all happens in your browser. Create a fine-grained token scoped to just this one repo at github.com/settings/tokens, with Contents: Read and write and Actions: Read and write permissions (the second one lets this page trigger a price pull for you after adding a card). The token is stored only in this browser's local storage — it's never sent anywhere except directly to GitHub's API.
